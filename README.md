# karriere — интерактивные проекты ИПУ РАН

Статические веб-приложения, размещаемые на GitHub Pages:

- [`квест_v3_ipad/`](квест_v3_ipad/) — квест по ИПУ РАН (10 вопросов, призы, версия для iPad)
- [`интерактив_v2/`](интерактив_v2/) — «Распределяющая шляпа»: магия выбирает лабораторию

Открыть: https://lmberlin99.github.io/karriere-/

## Как обновить

1. Измените нужный файл локально.
2. Загрузите его в ту же папку репозитория (GitHub → Add file → Upload files).
3. Через 1–2 минуты GitHub Pages обновит сайт автоматически.

> Если после правок вопросы не обновляются на iPad — поменяйте номер кэша в `sw.js`
> (например, `ipu-quiz-v3-1` → `ipu-quiz-v3-2`) и загрузите его тоже.
