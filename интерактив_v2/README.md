# Распределяющая шляпа v2 — ИПУ РАН

Вторая версия интерактива: новая «милая» фиолетовая шляпа, магический стартовый экран (звёздное небо, конфетти, пульсирующая кнопка) и расширенные страницы лабораторий с фото заведующих, направлениями, фактами и навыками.

## Запуск

Откройте `index.html` в браузере (двойной клик) или запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000/интерактив_v2/
```

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | разметка экранов |
| `style.css` | оформление (тёмная магическая тема, конфетти, звёзды) |
| `app.js` | логика: клик → загрузка → случайная лаборатория → слайд |
| `data/labs.js` | **слайды/данные лабораторий — редактируйте здесь** |
| `manifest.webmanifest` | настройки PWA (иконка, имя, standalone) |
| `sw.js` | service worker: кэш для работы офлайн |
| `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` | иконки приложения |
| `assets/labs/` | фото заведующих (lab01.png, lab02.jpg, ...) |

## Установка на Android (PWA)

Это PWA — ставится как обычное приложение из Chrome, без магазина:

1. Разместите папку на HTTPS-сайте (или локальный HTTPS-сервер — см. квест).
2. Откройте адрес в Chrome на Android.
3. Меню Chrome (⋯) → **«Добавить на главный экран»** → «Установить».
4. Появится иконка «Шляпа ИПУ»; после первого открытия работает офлайн (кэш `sw.js`).

## Как редактировать слайды

Все тексты — в `data/labs.js`. Файл данных полностью отделён от интерфейса.

1. Откройте `data/labs.js`.
2. Найдите лабораторию по `num`.
3. Измените текст, сохраните, обновите страницу (F5).

Поля одного блока:

```js
{
  num: "1",                    // номер лаборатории (для поиска)
  name: "Лаборатория № 1 «...»", // официальное название
  short: "Короткое название",    // резервное поле
  emoji: "🚀",                  // иконка
  role: "Повелитель ракет",      // суперспособность (заголовок)
  joke: "Вердикт шляпы...",      // шутка-приговор
  description: "1-2 предложения о лаборатории",
  directions: ["направление 1", "направление 2"],  // чипы
  what: ["чем будешь заниматься 1", "..."],          // список
  facts: ["факт 1", "факт 2"],                      // карточки
  skills: ["навык 1", "навык 2"],                   // чипы «что прокачается»
  leader: {
    name: "Фамилия Имя Отчество",
    degree: "учёная степень",
    photo: "assets/labs/lab01.png"   // можно null — тогда заглушка 🧙
  },
  url: "https://www.ipu.ru/node/11878"  // ссылка «Подробнее»
}
```

Добавление новой лаборатории: скопируйте любой блок `{ ... },` и вставьте перед `];` — шляпа начнёт выдавать её автоматически.

## Фото

- Фотографии заведующих скачаны со страниц «Информация о лаборатории» ipu.ru в `assets/labs/`.
- Для лаборатории № 3 фото на сайте нет — в данных указан `photo: null`, показывается заглушка-эмодзи.
- Чтобы заменить фото: положите файл в `assets/labs/` и укажите его в `leader.photo`.

## Источник данных

Названия, факты, направления и имена заведующих взяты со страницы `https://www.ipu.ru/structure/laboratories` и страниц «Информация о лаборатории» (ссылки в `url`).
