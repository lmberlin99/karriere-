# Квест по ИПУ РАН (v3 — для iPad)

Проверь себя: 10 случайных вопросов об институте, его лабораториях и великих учёных. После каждого ответа — верно/неверно и пояснение. В конце — итог и **приз**: чем больше правильных ответов, тем круче подарок.

**Иерархия призов:**
- 0–4 правильных — 🧟 **Мумия**
- 5–7 правильных — 🍾 **Открывашка**
- 8–10 правильных — 📱 **Подставка для телефона**

Версия специально свёрстана под **iPad** (крупные кнопки, крупный шрифт, тач-таргеты).

## Как установить на iPad (PWA) — офлайн без интернета

Квест можно поставить на iPad и пользоваться **без интернета** (после первого открытия). Важно: офлайн-кэш в Safari работает только по **HTTPS**. Обычный `http://` (как на `:8899`) даёт лишь закладку, которая при отключении сети попросит интернет. Поэтому используем локальный HTTPS-сервер из этой папки.

### Шаг 1. Поднять HTTPS-сервер на компьютере
Дважды кликните `запустить_квест.bat` (должен открыться чёрный «терминал» и написать «HTTPS-сервер квеста запущен»). Окно не закрывайте до конца установки.

- Нужен установленный Python (на этом ПК он есть).
- Сервер слушает порт **8443**; адрес для iPad: `https://192.168.31.66:8443/`
- Если IP компьютера изменился (другой Wi-Fi, роутер), перегенерируйте сертификат:
  `python _make_cert.py <новый-IP>` и перезапустите сервер. Текущий IP показывает `ipconfig` (раздел Ethernet/Wi-Fi → «IPv4-адрес»).

### Шаг 2. Установить сертификат на iPad (один раз)
Чтобы Safari доверял нашему самоподписанному сертификату:
1. В Safari на iPad откройте `https://192.168.31.66:8443/server.crt` (или `http://192.168.31.66:8899/квест_v3/server.crt` через временный сервер) и согласитесь на загрузку.
2. Настройки → «Загруженный профиль» → установите профиль «ipu-quiz.local» (пароль iPad).
3. Настройки → Основные → **Об этом устройстве → Настройка доверия сертификатам** → включите доверие для «ipu-quiz.local».
4. Перезагрузите Safari (закройте вкладки).

### Шаг 3. Открыть квест и добавить на «Экран "Домой"»
1. В Safari откройте `https://192.168.31.66:8443/` (сервер должен быть запущен).
2. Подождите 2–3 секунды, пока закэшируются файлы (служебный `sw.js`).
3. «Поделиться» → **«На экран "Домой"»** → «Добавить».
4. Отключите Wi-Fi/интернет и откройте иконку — квест должен запуститься офлайн.

### Как обновлять вопросы
Кэш обновляется при изменении файлов **только при сервере на компьютере** и обновлении номера кэша в `sw.js` (`CACHE_NAME = "ipu-quiz-v2"` и т.д.). Приложение на iPad перезапросит файлы, когда снова откроете его при запущенном сервере.

> ⚠️ Старое приложение, добавленное с `http://...`, удалите с iPad (удержание иконки → «Удалить приложение»), иначе при отключении сети оно будет требовать интернет.

## Запуск

Откройте `index.html` в браузере (двойной клик) или запустите локальный сервер:

```bash
python3 -m http.server 8899
# затем откройте http://localhost:8899/квест_v3/
```

## Как редактировать вопросы

Все вопросы в `data/questions.js`. Каждый — отдельный объект:

```js
{
  q: "Текст вопроса?",
  options: [
    "Вариант 1",   // индекс 0
    "Вариант 2",   // индекс 1
    "Вариант 3",   // индекс 2 — правильный
    "Вариант 4"    // индекс 3
  ],
  correct: 2,                       // индекс правильного ответа (с 0)
  notIpu: true,                     // необязательно: вопрос «не ИПУ» — гарантированно попадает в игру
  explain: "Пояснение после ответа.",
  source: "https://..."             // необязательно, для проверки
}
```

- В банке сейчас 54 вопроса; на каждую игру случайно выбираются 10.
- Хотите больше вопросов — просто добавьте новые объекты в массив (через запятую).
- Есть вопросы «наоборот»: правильный ответ — не ИПУ (Понтрягин, Беллман, Канторович, Deep Blue, «Эльбрус», ISARC), но в вариантах всё равно есть «родные» для ИПУ ловушки. Помечайте их полем `notIpu: true` — такие вопросы гарантированно попадают в каждую игру (сейчас минимум 2).
- Чтобы вопрос всегда выпадал (например, про «Каиссу»), добавьте ему поле `required: true` (в `app.js` сейчас выбор случайный — при необходимости скажите, и я добавлю гарантированный минимум).
- Приз зависит от счёта (от слабого к сильному): 0–4 — мумия, 5–7 — открывашка, 8–10 — подставка для телефона.
- После правки вопросов увеличьте `CACHE_NAME` в `sw.js` (`ipu-quiz-v3-1` → `v3-2` и т.д.), иначе установленное на iPad приложение покажет старые вопросы из кэша.

## Источник фактов

Факты основаны на официальных страницах `https://www.ipu.ru/` (историческая справка, страницы лабораторий, презентация об институте). Проверяйте формулировки перед публикацией.
